## 使用说明

1. 先打开 Skill 链接阅读完整目录，而不只看 `SKILL.md`。
2. 检查许可证、脚本、网络访问、凭据读取和环境要求。
3. 在隔离目录或容器中测试，不要自动安装到主力 Agent 环境。
4. 真正采用前，使用同一任务进行“加载 Skill / 不加载 Skill”的 A/B 验证。
